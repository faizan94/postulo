# Postulo frontend

Next.js 16 (App Router, Cache Components), React 19, Tailwind CSS 4, shadcn/ui, Recharts, TanStack Query.

Flow: **login -> onboarding (CV upload/paste -> review) -> first search runs automatically -> matches (skill chart, Learn next, job cards) -> job detail (scores, skills, full post, apply)**, plus New search, History, Settings and the "How it works" judge view.

## Run

```bash
npm install
npm run dev          # http://localhost:3000
```

The UI needs the backend on `http://localhost:8000`. Start it with `npm run dev:backend` from the repo root. With `MOCK_MODE=true` it serves fake data, so no keys are needed.

## Scripts

| Script | What it does |
|---|---|
| `npm run dev` | Dev server (Turbopack) |
| `npm run build` | Production build (`output: "standalone"`) |
| `npm start` | Serve the production build |
| `npm run lint` | ESLint (`eslint-config-next`) |
| `npm run typecheck` | `tsc --noEmit` |

## Config

| Variable | Default | Note |
|---|---|---|
| `NEXT_PUBLIC_API_URL` | `http://localhost:8000` | Backend URL as seen from the browser. It is inlined at **build** time, so rebuild after changing it. For local dev, put it in `frontend/.env.local` or export it before `npm run dev` |

## Code map

| Path | What it does |
|---|---|
| `src/app/` | Routes: `login`, `(app)/onboarding`, `search/[id]`, `search/[id]/job/[postingId]`, `new-search`, `history`, `settings`, `how/[id]` |
| `src/features/auth/` | `AuthProvider` (token in localStorage, `/api/me`), `homePath` |
| `src/features/cv/` | Upload/paste and the review step |
| `src/features/search/` | Titles and places inputs, `useSearchLive` (stream + cache patching + polling fallback) |
| `src/features/results/`, `job/` | Progress, job cards, score ring, badges, skill chart, Learn next, post text with highlights |
| `src/components/ui/` | shadcn/ui components |
| `src/lib/` | `api/` (one function per endpoint), `sse.ts`, `types.ts` (mirrors `backend/app/schemas/`), `status.ts`, `format.ts` |

`AGENTS.md` was generated by create-next-app. It tells AI coding agents to read the bundled Next.js 16 docs in `node_modules/next/dist/docs/`.

## Docker

```bash
docker build --build-arg NEXT_PUBLIC_API_URL=http://localhost:8000 -t postulo-frontend .
docker run --rm -p 3000:3000 postulo-frontend
```

The image is built in three stages (deps → build → runner). The runner uses `node:22-alpine`, copies only the standalone server, runs as non-root user `nextjs`, and has a healthcheck.
