# Postulo frontend

A Next.js 16 app (App Router, TypeScript, Tailwind CSS 4, ESLint), created with `create-next-app@16.4.2`.

The flow is a single page: **upload CV → preferences (Berlin / Germany / World + free text) → results**. Results show posting cards with a star score, verified badges, and gold/orange/red skill chips, next to the agent trace and the list of removed ghost jobs.

## Run

```bash
npm install
npm run dev          # http://localhost:3000
```

The UI needs the backend on `http://localhost:8000`. Start it with `npm run dev:backend` from the repo root. With `MOCK_MODE=true` it serves fake data, so no keys are needed.

## Scripts

| Script | What it does |
|---|---|
| `npm run dev` | Dev server (Turbopack) |
| `npm run build` | Production build (`output: "standalone"`) |
| `npm start` | Serve the production build |
| `npm run lint` | ESLint (`eslint-config-next`) |
| `npm run typecheck` | `tsc --noEmit` |

## Config

| Variable | Default | Note |
|---|---|---|
| `NEXT_PUBLIC_API_URL` | `http://localhost:8000` | Backend URL as seen from the browser. It is inlined at **build** time, so rebuild after changing it. For local dev, put it in `frontend/.env.local` or export it before `npm run dev` |

## Code map

| Path | What it does |
|---|---|
| `src/app/page.tsx` | Page shell (header, footer) |
| `src/components/PostuloFlow.tsx` | Client-side state machine for upload → preferences → results |
| `src/components/PostingCard.tsx` | One posting: title, company, score, badges, skills, why |
| `src/components/SkillChip.tsx` | Gold/orange/red chip and legend dot |
| `src/components/StarScore.tsx` | Five-star display with half-star fill |
| `src/components/VerifiedBadges.tsx` | `company_exists` / `posting_live` / `recent` badges |
| `src/components/AgentTrace.tsx` | Agent trace and removed ghost jobs |
| `src/lib/api.ts` | `getHealth`, `uploadCv`, `searchJobs`; parses backend errors |
| `src/lib/types.ts` | TypeScript mirror of `backend/app/models/schemas.py` |

`AGENTS.md` was generated by create-next-app. It tells AI coding agents to read the bundled Next.js 16 docs in `node_modules/next/dist/docs/`.

## Docker

```bash
docker build --build-arg NEXT_PUBLIC_API_URL=http://localhost:8000 -t postulo-frontend .
docker run --rm -p 3000:3000 postulo-frontend
```

The image is built in three stages (deps → build → runner). The runner uses `node:22-alpine`, copies only the standalone server, runs as non-root user `nextjs`, and has a healthcheck.
